# Contributor Covenant Code of Conduct

## Our Pledge

We pledge to make participation in **Kokerqualizer** a harassment-free, welcoming, and respectful experience for everyone, regardless of background or experience level.

## Expected Behavior

- Use welcoming and inclusive language.
- Respect differing viewpoints and constructive technical feedback.
- Focus on what is best for users and the project.
- Show empathy and patience toward other contributors.

## Unacceptable Behavior

- Harassment, trolling, insulting comments, or personal attacks.
- Publishing others' private information without explicit permission.
- Conduct inappropriate in a professional open-source community.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, issues, or pull requests that violate this Code of Conduct.
