# Kokerqualizer

Custom plain-Java Android equalizer & audio deck (`com.buddyapps.kokerqualizer`, Android 9+ / API 28+).

## Highlights
- **Audio DSP**: Switchable 5/10-band EQ (`DynamicsProcessing`) with ISO & Car-Sub frequency modes, ±18 dB range, Smart Auto-Gain, 3-band Multiband Compressor (`Punch MBC`), Anti-Clipping Limiter, Bass Boost (`Tight` / `Deep` / `Boomy`), Preamp, 3D Virtualizer, L/R Balance, and A/B Flat compare.
- **UI & Visuals**: AMOLED dark Neon Shocking Green (`#39FF14`) theme with per-preset neon colors, live Spectrum Bars / Wave / Stereo VU + Clip LED visualizer, switchable vertical sliders / draggable spline curve, Smooth Brush painting, Undo/Redo, Preset Lock, and big retro rotary knobs.
- **Floating 3D Orb Companion**: System overlay 3D crystal orb with depth-of-field bokeh stardust forming a pulsating `K`, edge-snapping drag, and a floating quick-control popup card over any app.
- **In-App YouTube Playlists**: Multi-playlist live sync on startup and every 15 minutes, built-in player with auto-fallback for label-blocked embeds, full YouTube web sign-in support, and Car Mode integration.
- **Car Mode & Device Automation**: Adaptive portrait/landscape Car Mode with Highway Boost (+3 dB), live visualizer backdrop, Bluetooth per-device auto-start + optional connect volume, wired/USB-C headphone auto-switching, Quick Settings tile, interactive notification, Home Screen widget, Sound Test suite, and Audio Health Check.
